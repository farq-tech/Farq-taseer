# سكربت النصوص — اكتب نصك هنا

املأ عمود **نصك**. لا تغيّر عمود **المعرّف**.
لما تخلّص، أرسل الملف وأركّب كلامك على الواجهة كما هو.

الصوت المطلوب منك: عامية سعودية واضحة، قصيرة، بدون مبالغة تسويقية.

## ملاحظات لك وأنت تكتب
- لا تذكر اسم المصدر في انتظار البحث. استخدم جملة انتظار واحدة فقط.
- الأزرار قصيرة: فعل + مفعول، بدون شرح.
- إذا السطر توضيحي، جملة واحدة تكفي.
- `{n}` و`{m}` و`{sector}` تبقى كما هي؛ هذي أرقام أو أسماء تتعبّى من النظام.
