# Taseer supplier quality and bounded buyer outreach

The buyer reviews their editable message and the selected suppliers before sending.
An action may address at most 50 distinct provider seller identities. Listings do not
consume this cap; the server rejects oversized requests before any debit or send.
Existing plan entitlements still apply. Search pagination does not spend credits.

Exact eligible matches rank ahead of near matches. Eligibility continues to distinguish
services from goods and apply city/specification checks. The selection shortcut uses
this ranking, skips near matches and picks each seller once. It never sends a message.

Provider UNKNOWN outcomes are visible and require reconciliation, not a blind retry.
A supplier reply remains evidence of a reply even if an earlier attempt is unresolved.

Offer details are rendered with explicit unknown terms. A recorded total does not prove
tax coverage, delivery inclusion, availability or lead time. The clarification button
only fills a draft; the buyer must review it and explicitly send.

Release evidence is separate for local tests, merged sources, API/UI deployments and
native Capgo rollout. No live outreach is authorized by implementation tests.
