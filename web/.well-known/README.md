# Apple Pay domain association

Place the Moyasar "Domain Association" file here as:

`apple-developer-merchantid-domain-association`

(no extension). Or set `MOYASAR_APPLE_PAY_ASSOCIATION` in the host environment.

Register the exact site hostname in Moyasar Dashboard → Settings → Apple Pay Domains
(for example `farq-taseer-phi.vercel.app`), then Validate and Register.
